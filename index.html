How to join
  1. Linux: install ZeroTier One, then join with sudo zerotier-cli join .
  2. Windows: use the ZeroTier tray menu and choose “Join New Network”.
  3. Android: add the network in the ZeroTier app and approve its VPN prompt.

The network owner may need to authorize your device. Install and setup help · Android setup

If you continue without joining, ElseMesh will still try a direct browser connection. Some networks may not allow it, which can interrupt access to a world or portal.
